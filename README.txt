AtlasERP Interactive Demo

1. Extract this ZIP.
2. Open index.html in Chrome, Edge, Firefox or Safari.
3. Sign in with User ID: admin and Password: admin.

Includes an interactive login, dashboard, sidebar navigation, module previews and sample multi-currency/crypto payment form.

IMPORTANT: This is a front-end demonstration only. No backend/database or live payment integrations are connected and data is not saved. Credentials are hard-coded and are NOT secure for production. Do not enter real customer, financial or payment information. Production deployment requires server-side authentication, password hashing, database persistence, permissions, CSRF protection, audit logs, backups, security testing and compliant payment-provider integrations.
